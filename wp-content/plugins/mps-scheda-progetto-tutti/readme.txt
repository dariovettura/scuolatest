Mostra tutti i progetti su /scheda-progetto/ rispettando l'ordinamento da Configurazione > Didattica.

== Description ==

Il tema Design Scuole filtra l'archivio progetti per anno scolastico corrente. Questo plugin:

* rimuove quel filtro (anche con ?archive=true)
* mantiene criterio e direzione da Configurazione > Didattica
* nasconde via CSS i pulsanti "anno in corso / anni scorsi"

Disattivando il plugin si torna al comportamento originale del tema.

== Installation ==

1. Carica la cartella `mps-scheda-progetto-tutti` in `/wp-content/plugins/`
2. Oppure zippa la cartella e installala da Plugin > Aggiungi nuovo > Carica plugin
3. Attiva il plugin
